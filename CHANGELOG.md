# Changelog

All notable changes to this project will be documented in this file.

## 0.2.0 - 2026-09-24

### Added

- Luna Reserve allowance display;
- Luna Reserve reset countdown;
- reserve discovery through `account/rateLimits/read` with Luna reserve support enabled.

### Changed

- the monitor window now expands automatically when the interface needs more vertical space;
- vertical resizing is enabled while width remains fixed;
- documentation now explains that Luna Reserve is a reserve-pool indicator, not proof of active Luna routing.

### Privacy

- no account IDs, conversation IDs, local usernames, fixed user paths, or private-project data are included.

## 0.1.0-rc1 - 2026-09-23

### Added

- standalone Windows desktop monitor;
- 5-hour and weekly allowance display;
- reset countdowns;
- reset-credit display when available;
- 30-second automatic refresh;
- desktop shortcut and Windows Startup installer;
- English and Russian documentation;
- privacy and security documentation.

### Notes

This was the first public release candidate.
