# Work Limits Monitor for Windows

Неофициальная компактная Windows-утилита для отображения лимитов Codex.

[English version](README.md)

> Статус: `0.1.0-rc1`, кандидат на первый выпуск. Код уже опубликован, но перед стабильной версией нужно проверить автономный публичный установщик на Windows.

## Зачем это нужно

При активной работе с Codex или ChatGPT Work постоянно возникает простой вопрос: **сколько осталось 5-часового и недельного лимита?**

Обычно для проверки приходится снова открывать страницу лимитов ChatGPT. Work Limits Monitor держит эти значения в небольшом окне Windows, которое можно оставить поверх рабочих окон.

Показывает:

- остаток 5-часового лимита;
- остаток недельного лимита;
- время до сброса каждого окна;
- доступные reset credits, если локальный сервис их возвращает;
- тип плана;
- автоматическое обновление каждые 30 секунд.

Утилита не запускает задачи ChatGPT Work, не отправляет промпты, не изменяет чаты и не расходует reset credits.

## Как это работает

Программа запускает установленный локально Codex CLI в режиме app-server и читает состояние лимитов методом:

`account/rateLimits/read`

Интерфейс показывает нормализованные значения, полученные от локального сервиса.

Это неофициальная пользовательская утилита. Интерфейс Codex app-server может измениться в будущих версиях Codex.

## Требования

- Windows 10 или Windows 11
- Python 3.10 или новее
- Codex CLI в `PATH`
- выполненный вход в Codex CLI

Сторонние Python-пакеты не требуются.

## Установка

В PowerShell из папки репозитория:

```powershell
cd path\to\work-limits-monitor-windows
.\install\install.ps1
```

Установщик:

1. проверяет Python и Codex CLI;
2. копирует программу в `%LOCALAPPDATA%\WorkLimitsMonitor`;
3. создаёт ярлык `Work Limits Monitor` на рабочем столе;
4. добавляет программу в автозагрузку текущего пользователя Windows;
5. запускает монитор.

После установки PowerShell можно закрыть.

## Ручной запуск

Через ярлык на рабочем столе или:

```bat
start.bat
```

## Удаление

```powershell
cd path\to\work-limits-monitor-windows
.\install\uninstall.ps1
```

## Конфиденциальность

В коде нет идентификаторов аккаунта, conversation ID, email, локальных имён пользователей или фиксированных пользовательских путей.

Программа только читает лимиты из локально авторизованного Codex CLI и не отправляет телеметрию или историю использования.

## Ограничения

- Используется локальный интерфейс Codex app-server, который может измениться.
- Утилита показывает значения окон лимитов, а не количество токенов.
- Проценты 5-часового и недельного окон не являются балансом токенов.
