# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0-rc1 - 2026-09-23

### Added

- standalone Windows desktop monitor;
- 5-hour and weekly allowance display;
- reset countdowns;
- reset-credit display when available;
- 30-second automatic refresh;
- desktop shortcut and Windows Startup installer;
- English and Russian documentation;
- privacy and security documentation.

### Notes

This is a release candidate. The first stable `0.1.0` release should follow a clean standalone installation test on Windows.
